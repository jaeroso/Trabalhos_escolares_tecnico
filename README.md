# Coletânea de Projetos - Desenvolvimento de Sistemas

Este repositório reúne uma coletânea de projetos, exercícios e trabalhos 
desenvolvidos durante o curso técnico em Desenvolvimento de Sistemas, 
integrado ao Ensino Médio.

Aqui você encontra desde exercícios simples de lógica de programação até 
projetos mais completos, envolvendo diferentes linguagens e tecnologias 
trabalhadas ao longo do curso.

## Organização
Cada pasta representa um projeto ou período do curso, contendo seu próprio 
código-fonte e, quando aplicável, uma breve documentação.

## Tecnologias
- HTML
- CSS
- JavaScript
- MySQL

## Coletânea de Trabalhos Escolares de Programação

### 1. Jogo da Memória

O Jogo da Memória é uma aplicação interativa feita com HTML, CSS e JavaScript, na qual o usuário deve encontrar pares de cartas com figuras de animais. O projeto possui embaralhamento, contagem de tentativas, sistema de dicas, reinício e modo escuro, demonstrando o uso de arrays, eventos, manipulação do DOM e classes CSS.

### 2. O Peso do Bullying

O Peso do Bullying é um site de conscientização que apresenta consequências do bullying para a saúde mental, as emoções, a vida social e o desempenho escolar. Desenvolvido com HTML, CSS e JavaScript, utiliza cartões informativos, efeitos visuais e um botão de ajuda para tornar a apresentação mais clara e impactante.

### 3. Calculadora de IMC

A Calculadora de IMC recebe peso e altura, calcula o Índice de Massa Corporal e apresenta uma classificação correspondente. Desenvolvida com HTML, CSS e JavaScript, a aplicação utiliza validação de dados, operações matemáticas e estruturas condicionais para gerar o resultado, podendo ser aprimorada com regras de validação mais completas.

### 4. MicroGym Express

O MicroGym Express é uma página conceitual que apresenta uma proposta de miniacademias automatizadas, com reserva de horários, acesso por QR Code, treinos digitais e atendimento remoto. O projeto foi desenvolvido apenas com HTML e funciona como uma apresentação da ideia, sem implementar efetivamente o aplicativo ou o sistema de reservas.

### 5. Conversor de Moeda USD para BRL

O Conversor de Moeda transforma valores em dólares para reais usando uma cotação fixa de R$ 5,50. Feito com HTML, CSS e JavaScript, demonstra entrada de dados, cálculo matemático e atualização do conteúdo da página, podendo futuramente utilizar uma cotação obtida por API.

### 6. EduBalance

O EduBalance é um dashboard educacional sobre o equilíbrio entre tecnologia e estudos, apresentando textos, métricas, perfis de estudantes, gráficos e recomendações. Desenvolvido com HTML, CSS, JavaScript e Chart.js, utiliza abas, tabelas e visualizações de dados; seus valores são estáticos e servem como exemplos demonstrativos.

### 7. Amigo Secreto

O Amigo Secreto permite cadastrar nomes e sortear aleatoriamente um participante. Desenvolvido com HTML, CSS e JavaScript, utiliza arrays, eventos, validação de campos e Math.random(). A versão enviada realiza a escolha de um nome, mas ainda não distribui pares completos nem impede repetições.

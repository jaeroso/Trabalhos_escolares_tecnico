# Coletânea de Projetos - Desenvolvimento de Sistemas

Este repositório reúne uma coletânea de projetos, exercícios e trabalhos 
desenvolvidos durante o curso técnico em Desenvolvimento de Sistemas, 
integrado ao Ensino Médio.

Aqui você encontra desde exercícios simples de lógica de programação até 
projetos mais completos, envolvendo diferentes linguagens e tecnologias 
trabalhadas ao longo do curso.

## Organização
Cada pasta representa um projeto ou período do curso, contendo seu próprio 
código-fonte e, quando aplicável, uma breve documentação.

## Tecnologias
- HTML
- CSS
- JavaScript
- MySQL
